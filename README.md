# PMLife Labs 🧪 (Engine 3D & Frontend Showcase)

Repositório público de Pesquisa e Desenvolvimento (P&D), Spikes de Arquitetura, benchmarks de SQLite WASM e PoCs de renderização 3D para a plataforma PMLife.

## 📂 Pastas de Experimentos
- `benchmarks/sqlite-wasm`: Testes de desempenho do banco local no navegador.
- `pocs/threejs-performance`: Testes de renderização 3D, câmeras e FPS.
- `pocs/inertia-php-cpanel`: Protótipos de integração do Inertia.js com PHP 8.2 na Hostgator.
- `pocs/npc-ai-prompt`: Experimentos com prompts e integração de LLMs para NPCs.
- `pocs/i18n-dynamic-loader`: Testes de carregamento dinâmico de pacotes de idiomas.
