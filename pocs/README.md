# PoCs (provas de conceito)

Uma pasta por PoC, com o prefixo `poc-` (ex.: `pocs/poc-r3f-third-person-avatar/`).

PoC aqui é a prova de que **uma rotina ou funcionalidade do produto é viável**, em formato **demonstrável** a cliente ou investidor: tem uma demo navegável (`public/` ou `dist/`) e um `README.md` que explica, em linguagem de negócio, o que está sendo provado.

Investigação puramente técnica (tecnologia nova, lib A × lib B, técnica de arquitetura, segurança ou infra) vai em [`../spikes/`](../spikes). Medição de desempenho vai em [`../benchmarks/`](../benchmarks).

Este repositório é público: use **dados fictícios** e nunca conteúdo proprietário (currículo das trilhas, system prompts, base de conhecimento, textos do ERP).
