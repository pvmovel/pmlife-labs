## Como andar

| Tecla | O que faz |
| :--- | :--- |
| **W** ou **↑** | anda para a frente |
| **S** ou **↓** | anda para trás |
| **A** ou **←** | gira para a esquerda |
| **D** ou **→** | gira para a direita |
| **C** | alterna entre o avatar e a visão orbital |

## Como interagir

Chegue perto de um prédio: aparece o aviso **"Pressione [E] para Entrar ou [I] para Informações"**.

- **I** abre as informações do prédio.
- **E** entra na sala e mostra as missões dela.
- **H** abre este guia, de qualquer lugar.
- **Esc** fecha a janela aberta.

> Enquanto você digita num campo de texto, os atalhos ficam desligados.

## Visão orbital

Arraste para girar a câmera e use a roda do mouse (ou o gesto de pinça) para aproximar. Em tela de toque o campus abre nesta visão.
